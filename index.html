SentinelX Cyber Twin

Next.js 15 React 19 FastAPI Gemini Flash EasyOCR SQLite/PostgreSQL

SentinelX Cyber Twin™ is a production-grade, AI-powered digital threat intelligence and personal cybersecurity companion. Unlike traditional scanners, it continuously tracks user interactions to construct a personalized profile named Cyber Twin™.

Core Telemetry Engine Formulation

The platform aggregates scanning logs and computes a risk factor based on a custom weighted formula:

\[\text{Risk Score} = (S_{url} \times 0.4) + (S_{ocr} \times 0.3) + (S_{rep} \times 0.2) + (S_{ai} \times 0.1)\]
  • URL Score (\(S_{url}\)): Assesses protocol security (HTTP vs HTTPS), subdomain depths, and keyword domain masquerades.
  • OCR Score (\(S_{ocr}\)): Extracts chat message text patterns via EasyOCR/Tesseract looking for social engineering urgency patterns.
  • Reputation Score (\(S_{rep}\)): Checks DNS history and blacklists.
  • AI Score (\(S_{ai}\)): Synthesizes text semantics with Gemini 2.5 Flash API calls to isolate fraud indicators.

AutoSRE: Autonomous Recovery Environment

PyTorch Reinforcement Learning Gymnasium Streamlit

Built for the Meta PyTorch OpenEnv Hackathon, AutoSRE transitions static log parsers into interactive environments. It establishes a live server crash scenario (e.g. mock crypto-miners spawning and maxing CPU cycles) and trains AI agents to solve it.

State-Action-Reward Cycle

  • State Observation: CPU usage, memory thresholds, process tables, and active sockets.
  • Action Space: Strictly defined commands: check_metrics, list_processes, kill_process [PID].
  • Reward Loop: +1.0 for returning server CPU metrics to baseline; -0.5 for terminating core databases or system services.
